# Банк заданий

Задания взяты из открытого банка **ФИПИ**.

## Что внутри

- `fipi_physics_2026.json` — 1 145 заданий ЕГЭ по физике.
- `media/ege_2026/` — картинки и графики к заданиям ЕГЭ.
- `oge_2026/tasks.json` — 77 заданий ОГЭ 9 класса.
- `oge_2026/topics.json` — разделы и темы ОГЭ.


## Типы ответов

- число;
- выбор нескольких вариантов;
- код из цифр, например `11`, `22`, `333`;
- измерение, например `450,012,5`.

## Как добавить задания

```bash
python scripts/import_fipi.py \
  --pdf-dir "/путь/к/PDF" \
  --out content/fipi_physics_2026.json \
  --media-dir content/media/ege_2026
```

Импортёр проверяет ответы и не добавляет задание, если не может определить ответ.


## Проверка ОГЭ

```bash
python scripts/analyze_oge_bank.py
```

Скрипт проверяет покрытие тем, считает задания с числовыми величинами и
формирует `oge_2026/llm_review.jsonl` — промпты для выборочной LLM-проверки
перед ручным тестированием.
